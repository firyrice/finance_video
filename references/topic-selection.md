# 选题方法论（财经垂类）

> 本模块把"从一支股票到一个能爆的选题"的判断逻辑讲透。核心不是"想 3 个角度"，而是先过 4 个判断关（好问题 → 动机 → 比较优势 → 反直觉），再从可轮换的选题池里挑，最后走一遍准入自检。产出仍是 **3 个差异最大的选题方案**，供用户在阶段一决策点选择。

## 起点：选题首先是一个"好问题"

一个选题在成为选题之前，先得是一个**有一大批股民正在心里问、却没人给出满意答案的好问题**。不是"我想讲这支票的什么"，而是"关注这支票的人此刻在纠结什么"。拿到股票和抓来的数据后，先把它写成一个问题，过三关：

1. **有多少人真的在问**——看雪球热帖的 `reply_count`/`hot_score`、股吧讨论热度。几百条回复在吵的那个点，就是有大量人在问的好问题；没人讨论的冷门票，好问题也稀薄。
2. **现有的答案够不够好**——市面上（其它财经号、研报、股吧）对这个问题的回答，是不是都在讲正确的废话（"长期看好""注意风险"）？答案越烂、越含糊，你讲清楚的价值越大。
3. **蛋炒饭凭什么给出更好的答案**——见下方"比较优势"。三关都过得去，才进入下面的打磨；过不去，这个角度就不成立，换一个。

## 第一层：动机——股民凭什么点开

任何一条财经视频被点开，都是因为它命中了观众的某种动机。选题前先想清楚给的是哪一种：

- **信息服务**：帮观众把一支股票**看明白**——这门生意好不好、现在这个价贵不贵、该盯哪些变量。标准是"看完后他自己对这支股票的判断比看之前更清晰"，不是数据堆得多。**注意边界**：我们没有投顾牌照，选题可以立成"这只股票到底怎么样""套牢的人该怎么看这局"，但**不能立成"教你几块买、几块卖"**——那是荐股，平台直接封（见 SKILL.md「荐股红线」）。选题问的是"值不值、变量在哪"，不是"替你下单"。
- **情绪价值**：给观众情绪上的满足或释放——共鸣、宣泄、被理解、抄底的爽感、看空的优越感。标准是精准命中股民的心声，不是 UP 主自己想抒发。

**关键规律：驱动点击最强的三种情绪是恐惧、愤怒、希望，其次才是好奇、优越感、共鸣。** 财经垂类这三种情绪极其现成，选题时先把这支股票能触发的具体情绪点列出来（要具体到能对应内容的颗粒度，不是抽象说"制造焦虑"）：

- **恐惧**：怕套牢加深、怕财报暴雷、怕高位接盘、怕退市、怕错过止损点。
- **愤怒**：气被机构/主力收割、气财报造假、气大股东高位减持、气自己追高被套。
- **希望**：盼抄底反弹、盼困境反转、盼这次是真的底、盼跟对一次翻身。

弱动机（好奇、深度拆解）不是不能做，但要靠更硬的反直觉点或更强的比较优势补回来。**选题阶段判断错动机强弱，后面标题再打磨也补不回来**——这与标题方法论的动机排序完全一致。

## 第二层：比较优势——凭什么是"蛋炒饭"讲的这条被点开

这支股票大概率已经有一堆号讲过。选题能不能立住，取决于蛋炒饭有没有一个说得清的比较优势。五种里挑最突出的 1-2 个，别想全占：

1. **更专业**——七维分析框架 + 雪球一手行情/资金数据，比情绪化的股吧喊单硬。
2. **更易懂**——把 PE 分位、护城河、DCF 这些黑话翻译成大白话，比研报和服务顾问的术语轰炸让人愿意听。
3. **更有戏剧性**——把一份财报、一次涨停讲出反转和冲突。
4. **更有代入感**——蛋炒饭是散户中的一员（用"咱们"），不是高高在上的分析师。
5. **更有观点**——敢站队、敢给明确的买卖建议和价位，不骑墙。这是财经号最稀缺的，多数号都在"仅供参考"里和稀泥。

判断标准很硬：把蛋炒饭这条和头部同类内容并排放，能不能一句话说清"我强在哪"。说不清就换角度。选 1-2 个而非全占，是因为后面的文稿、标题、封面都要围绕这 1-2 个优势去强化。

## 第三层：反直觉点——同等信息量下的放大器

同样一支股票，带反直觉结论的比平铺"XX 分析"点击率明显更高。三步：

1. 找出股民对这支股票的**默认预期/共识印象**——必须真实存在、市场普遍持有，不能自己发明稻草人。（"都以为茅台是永远的神""都觉得宁王要完""公认的低估白马"）
2. 找一个和这个共识相悖、但数据上站得住的点。
3. 反直觉点越具体、越可验证，势能越强；站不住的只会沦为标题党、反噬信任（也踩合规红线）。

- ❌ 假反直觉："这只股票其实不贵"——如果它 PE 明明在高位，这是自己发明的前提。
- ✅ 真反直觉："账上现金比市值还多，市场却当它要退市"——共识（市场看衰）真实存在，反转（现金流数据）可验证。

不强求每个选题都有反直觉点，但同一批候选里，有扎实反直觉点的排前面。

**差异化角度 = 主动放弃大家都盯的那个点。** 反直觉不只是"给个相反结论"，更高级的一招是**主动错开市场共识的焦点**：全网都在盯同一个变量时，你偏不讲它，转去讲一个被忽略、却真正决定结果的变量。这本身就是一次强反直觉。

- ✅ 紫金矿业股价腰斩，全网都在争"金价还会不会跌"——高播那条偏偏说"今天不聊金价，聊资源"，转去讲产能、降本、铜锂对冲。焦点一换，信息增量感立刻拉满。
- 做法：先问"关于这支股票，现在 90% 的人都在盯哪个点？"——那个点往往已经被讲烂、边际信息为零。再找一个"大家没在看、但数据上更能解释走势"的点作为主角。
- 护栏：错开的焦点必须**你手里有数据能讲扎实**（呼应下方准入自检第 5 条），否则就成了为不同而不同的标新立异。

## 第四层：选题池——建立可轮换的角度库（防重复、防偏科）

爆款不靠灵感。每次从池子里挑，而不是从零现想。财经六类角度池，一次选**差异最大的 3 个**（不要三个都落在同一类）：

- **争议判断型**：给一个反共识的鲜明结论（"茅台还能不能买"）。命中：优越感/认同 + 希望/恐惧。
- **事件驱动型**：抓最新催化（财报、涨停、暴跌、政策、减持）。命中：好奇 + 恐惧。热度最高但有时效，趁热做。
- **对比型**：和竞品/行业/历史自己对比（"宁王 vs 比亚迪""现在 vs 2021 高点"）。命中：好奇 + 判断依据。
- **答疑解惑型**：解答散户最纠结的问题（"套牢了要不要割""现在上车是抄底还是接盘"）。命中：恐惧 + 希望，代入感最强。
- **深度拆解型**：把商业模式/护城河/财报讲透。命中：信息服务，弱动机，靠专业优势撑。
- **风险预警型**：泼冷水，指出被忽视的风险。命中：恐惧，最容易出爆款但别连做（观众会疲劳）。

**从雪球热帖直接捞选题**：`hot_score` 高、`reply_count` 大的帖子在吵什么，往往就是现成的争议判断型/答疑解惑型选题；`top_comments` 里的高赞分歧点，就是散户此刻最真实的情绪焦点。

## 第五层：热点结合——势能杠杆（选用，别牵强）

热点是放大器不是必需品。只在"确实有交叉点、结合不牵强"时用。财经的热点有两类：

- **突发**：财报季暴雷/超预期、涨跌停、政策落地、行业黑天鹅、大额减持/回购。
- **周期性节令**：财报季、年报预告期、分红除权、季度调仓、年末效应——比突发更稳、可提前布局。

判断牵强与否：把结合后的选题读给一个只关心这支股票的股民听，他觉不觉得这个连接自然。牵强蹭热点稀释账号专业感，得不偿失。

## 第六层：准入自检——3 个方案交付前逐条过

每个候选选题交付前过一遍，通不过就重打磨：

1. **动机明确**——一句话说清主要给信息服务还是情绪价值，命中恐惧/愤怒/希望哪一种。
2. **优势清晰**——一句话说清相比同类的 1-2 个比较优势（蛋炒饭独有的：专业框架 / 接地气 / 敢站队）。
3. **可持续**——能归进上面某一类选题池，不是孤立点子。
4. **具体性**——不是泛泛的"XX 股票分析"，具体到某个数据事实/某个说法/某个价位。
5. **可执行性（财经硬门槛）**——你手里有没有支撑这个角度的**真实数据**？雪球行情、财报数字、研报观点、散户情绪，至少要有一类硬料能把这个角度讲扎实。**光有钩子、没有数据支撑的角度，就是标题党，直接砍**——财经内容缺数据支撑等于误导投资决策。
6. **热点不牵强**——若结合了热点，连接自然才保留。

## 输出格式（3 个方案）

好的财经选题 = 一个真实的数据事实 × 一个股民关心的情绪/问题 × 一个让人忍不住点进来的钩子。三个方案走差异最大的三个角度：

```
## 选题 N：[一句话选题方向]

**核心角度**：这条视频讲什么、站什么立场
**命中动机**：恐惧 / 愤怒 / 希望 / 信息服务（哪一种，一句话说清戳的是哪根神经）
**比较优势**：蛋炒饭凭什么讲这条比别人好（1-2 个）
**选题池**：属于六类里的哪一类
**开场钩子**：前 5 秒的具体第一句话（含公司名 + 一个数字或反差）
**内容主线**：3-4 个 bullet，讲清论证脉络
**预估热度**：⭐⭐⭐⭐☆ + 一句话说明（命中的动机强弱 + 蹭的热点 + 反直觉点强度）
**适合人群**：谁会点这条
```

三个方案给完，用一句话邀请用户选择，例如："你想做哪个方向？选定后我出完整口播稿、标题和封面。也可以说'把选题 2 改成更看空'。"然后**停下来**，不要自己接着往下写。
