# 选题发现方法论（阶段零 · 从全市场反推该做哪只票）

> 这个模块解决的是另一个问题：**用户不知道今天做哪只股票**时，主动扫全市场，反推"做哪些股票的分析对『蛋炒饭财经』最容易起量"，产出一份推荐清单供选。方向和 `topic-selection.md` 相反——那个是"股票已定 → 3 个角度"，这个是"股票未定 → 该做哪只票"。选出票、用户挑一只后，才进入 `topic-selection.md` 出 3 个角度。

## 第一性原理：本账号吃的是「持仓焦虑流量」，不是「话题热度流量」

这是整个选题发现的地基，来自账号自己的复盘（`workspace/reports/2026-08-13_宇树热点为何没接住流量.md` 和 `workspace/huasheng.md` 第八节）：

- 宇树科技是全网大热点，账号也做了，**却翻车**——因为它是新股、没有存量套牢盘、一签 7.5 万的打新门槛把 99% 感兴趣的观众挡在门外。热度是全网的，跟点进来的人的钱没关系。
- 反过来，京东方、药明康德、恒瑞这类"有大量散户正拿着、正在纠结要不要割"的票，播放稳。五粮液靠强争议钩子冲到 19.3 万播放（虽然完播只有 4.28%，是另一个问题）。

所以选题发现的**第一问不是"什么最热"，而是"有多少人正拿着这只票、正在为它的钱焦虑、值不值得为自己的仓位点进来看一看"**。全市场每天几千只票在动，能起量的永远是那批"跟一大群散户的真金白银有关、且此刻正在被讨论"的。

**2026-08-18 全量横评后又加了一问（同样前置）**：涨粉率后五名全是"超大盘白马 + 全网都在讲的热点"，涨粉率前三名全是"有持仓盘、还没被全网铺满、能独家重算"的中盘票。所以**第二问是"这只票是不是已经被全网讲烂了"**——讲烂了就是吸粉黑洞，能带播放带不动粉。两问合并成一句：**看的人手里有没有仓 × 同题有没有被别人讲烂，两件事一起决定这只票值不值得做。**（详见 huasheng.md 8.3 选题光谱规律）

## 四信号打分模型

对每个候选票，按这四个信号心里过一遍。**信号 A（持仓焦虑）+ A2（独家性余量）是"与"的关系、权重并列最高**——两者都强才进推荐位（持仓焦虑榜）；A 强 A2 弱（有焦虑但全网讲烂了）不直接进推荐位，除非能找到独家角度；A 弱的票最多进热度破圈榜。

### 信号 A · 持仓焦虑深度（本账号命脉，最高权重）

问三件事：**有没有存量套牢盘？有没有人正在讨论？讨论的是不是"要不要割/还能不能拿"这种真焦虑？**

- **持有面要广**：大盘白马、知名龙头、抱团股（散户持有面广、认知门槛低）> 冷门小盘/题材妖股。名字观众一听就知道是啥公司的，天然有代入感。
- **套牢盘要厚**：距 52 周高点跌幅越大，套在山顶的人越多，焦虑越深。用 `xueqiu_quote.py` 的 `high52w` 对 `current` 算跌幅；`xueqiu_hot_stocks.py` 的跌幅榜直接就是这批票的富矿。跌得惨 + 名气大 = 持仓焦虑最浓。
- **正在讨论**：`xueqiu_hot_stocks.py` 人气热股榜靠前、`follow`(关注数) 高，或雪球热帖 `reply_count`/`hot_score` 高、评论区在吵。冷门到没人讨论的票，套得再惨也没有情绪流量。用 `xueqiu_hot_posts.py`（派子 agent 消化）坐实：评论区在吵"要不要割""还能不能拿""是不是要退市"就是强信号。
- **反例护栏（宇树教训，硬规则）**：**新股、次新股、高打新门槛票、刚上市没多久的票 → 没有存量持仓盘 → 信号 A 直接判弱，不进持仓焦虑榜**，只能作为热度破圈榜的候选，且要标注"参考宇树，可能吸粉/完播差"。

### 信号 A2 · 独家性余量（新增·与信号 A 同权重，2026-08-18 横评后引入）

问一件事：**这只票 / 这个角度，是不是已经被全网讲烂了？** 讲烂的题，边际认知增量趋近于零，吸粉必然差。两类高危：

- **超大盘白马**（茅台、五粮液、招行、宁德这类）：人尽皆知、人人都在讲，观众认知已饱和。
- **全网热赛道**（CXO、创新药、AI 算力、白酒这类）：大 V 同期都在做，你的点观众在别处听过多遍。

判断手段：`web_search.py` 搜"<股票名> 分析 / 还能买吗 / 怎么看"看同类内容密度；对比"这只票此刻最热的那几个话题点"是不是已经被铺满。**独家性余量不足的票，即便信号 A（持仓焦虑）强，也只在"能找到全网没人讲的独家角度"时才推荐**——找不到，降级到热度破圈榜或直接跳过。这条和信号 A 是"与"的关系：A 强 A2 弱 = 有焦虑但无独家性（茅台就是典型，涨粉率 0.26% 垫底），不能只凭 A 强就进推荐位。

### 信号 B · 热度破圈势能

`xueqiu_hot_stocks.py` 的榜单排名（人气/涨幅/跌幅/成交额）+ `web_search.py` 搜到的当日催化：涨停板、跌停、龙虎榜、财报季业绩、政策落地、行业黑天鹅。有强催化、有话题度的排前面。**这个信号单独强、但信号 A 弱的票，进热度破圈榜而不是推荐位**——它可能带来一波泛流量，但对本账号的转化没保证。

### 信号 C · 账号适配度

- **去重（不是"做过就永久拉黑"，是"隔够时间 + 有新变化才值得重做"）**：读 `workspace/` 下已有视频文件夹名和发布日期。做过的票**同时满足这两个条件**才重新推荐——① **间隔够长**：距上次做这只票已过**月级别**以上（刚做完的票隔几天再报，观众会腻）；② **股票有较大变化**：出了新财报/公告、基本面有实质变动、或股价有较大波动（又一波暴跌/暴涨、突破关键位）。间隔够但没新变化 → 没新料可讲，跳过；有新变化但刚做没多久 → 再等等。两个都满足时，是"老票新故事"，反而是好选题。
- **板块轮换**：看已做票的板块分布，避免连着做同板块造成观众疲劳，优先补没做过或做得少的板块。
- **七类选题池能否成立**：这只票能不能落进 `topic-selection.md` 的七类（争议判断 / 事件驱动 / 对比 / 答疑解惑 / 深度拆解 / 风险预警 / 共识聚合）里差异化的一类。落不进任何一类的，说明角度不成立。
- **评论区反哺**：若某已做视频的 `评论回复.md` 里记了高频追问（有的文件明确注明"高频评论=下期选题素材"），把被反复问到的关联票 / 续集选题直接作为一路候选——这是观众亲口点的题。

### 信号 D · 数据支撑硬门槛

沿用 `topic-selection.md` 准入自检第 5 条：手里有没有真实数据（雪球行情、财报、研报、散户情绪）能把这个角度讲扎实？**光有热度、没有数据支撑的角度，就是标题党，直接砍**——财经内容缺数据支撑等于误导投资决策。发现阶段就要预判"这只票我出稿时抓得到料吗"，抓不到料的热闹票别推。

## 避坑规则（内化 huasheng 第八节，逐条守）

- **热点 ≠ 与我有关**：全网最热的票，若没有存量持仓盘（信号 A 弱），对本账号就是伪机会。宇树是活教训。
- **风险预警型别连做**：泼冷水的选题最容易出爆款，但连着做观众会疲劳、也会显得唱空成癖。看最近几支的选题类型，别扎堆。
- **高播 ≠ 高吸粉/高完播**：五粮液强争议钩子冲到 19.3 万播放，但完播率只有 4.28%——选题时就要预判"这只票的故事撑得住 10 分钟、留得住人吗"，不是只看能不能冲进来。留不住的强钩子票，标注这个风险。
- **超大盘白马 / 全网热点 = 吸粉黑洞**：茅台涨粉率 0.26% 全账号垫底、五粮液 0.53%、恒瑞 0.48%、药明 0.43%——都是超大盘白马或全网热赛道。这类票能带播放带不动粉，推荐前必须先找到全网没人讲的独家角度，找不到就降权（见信号 A2）。
- **发布时点与留存衰减**：财报季、周末等时点影响流量；账号近期处于留存衰减期时，更要挑故事性强、能撑完播的票。

## 合规红线（贯穿发现阶段）

发现阶段产出的"为什么适合""开场钩子雏形""建议方向"也必须落在**"值不值、变量在哪"**，绝不能出现"该买 / 目标价 / 买卖点位 / 分持仓操作建议"——沿用 SKILL.md「荐股红线」专节。钩子雏形可以写"XX 从山顶跌了一半，套牢的人还该拿吗"，不能写"XX 跌到 X 块可以抄底"。

## 输出格式（两栏，各 3-5 只候选，然后停下）

分两栏呈现，让用户一眼看清"稳的量"和"赌的量"：

```
## 🎯 持仓焦虑流量榜（推荐 · 本账号最稳的量）

### 候选 1：<股票名>（<板块>）
- **为什么适合本账号**：<一句话讲清存量套牢盘/正在讨论，带关键数字，如"距 52 周高点跌 X%、雪球评论区几百条在吵要不要割">
- **命中动机**：恐惧 / 愤怒 / 希望（哪一种，一句话说清戳哪根神经）
- **建议选题方向**：<七类选题池里的哪一类 + 一句话角度>
- **流量预判**：⭐⭐⭐⭐☆ · 弱/及格/爆 哪档 + 一句话（对标历史哪支，如"类比京东方套牢者代入"）
- **开场钩子雏形**：<含公司名 + 数字或反差的第一句雏形（不含买卖点位）>
- **状态标注**：<是否做过 / 板块是否与近期重复 / 数据支撑够不够>

### 候选 2：...（共 3-5 只）

## 🔥 热度破圈榜（高风险高回报 · 蹭当下热点）

### 候选 1：<股票名>（<板块>）
（同结构。新股/无存量持仓盘/纯题材票放这里，状态标注注明"破圈流量但可能吸粉/完播差，参考宇树"）
```

**每个候选给完，末尾用一句话邀请用户选一只**，例如：

> "想做哪只？定了我就按它进选题阶段出 3 个角度。也可以说'再挖几只医药的''只看跌得惨的白马''把候选 2 换个方向'。"

然后**停下来**——不要自动往下跑进阶段一出角度，也不要建视频文件夹。用户挑定一只后，才进 `topic-selection.md` 的流程。
