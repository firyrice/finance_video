# AI 味词表（财经口播稿专用）

> 这份表管的是**AI 腔**，跟合规红线里的"必涨/稳赚/安全边际"是两回事——那些是**荐股违规**（法律风险），这里是**读着像机器写的**（质量问题）。两张网都要过，别混。
>
> 用法：终审第一层（硬门禁）全文扫这张表，命中就替换或删。**这张表专为财经口播稿裁剪过**，凡是跟本 skill 其它规则打架的（比如标点、"先说结论"开场、数字精确度），已经剔除或标了例外，照着改不会自相矛盾。

---

## 一、AI 高频套话（删或换成人话）

一出现就暴露 AI 腔，绝大多数**直接删掉整句都不损失信息**：

- 值得注意的是 / 值得关注的是 / 不难发现 / 显而易见 / 众所周知
- 综上所述 / 总而言之 / 总的来说 / 由此可见 / 归根结底
- 从某种程度上说 / 在某种意义上 / 一定程度上
- 与此同时 / 更重要的是 / 更进一步说 / 换句话说 / 简而言之
- 本质上 / 究其本质 / 说到底（"说到底"仅结尾固定价值锚那句保留，正文中段别用）
- 意味着什么 / 这背后 / 这一切都指向

**判断法**：删掉这句，信息有没有少？没少就删。要衔接就用内容本身的转弯衔接，别用这些词当过场。

## 二、宣传腔大词（财经稿最爱踩，换成具体事实）

念研报、蹭政策时最容易堆这些空词，全部换成"具体是什么、具体多少"：

- 赋能 / 深度融合 / 生态闭环 / 协同效应（除非在讲公司确有的具体业务，否则删）
- 书写新篇章 / 注入新动能 / 迈上新台阶 / 打开新空间 / 站上新起点
- 范式转移 / 历史性节点 / 时代的浪潮 / 风口 / 大有可为 / 未来可期
- 硬核 / 王炸 / 天花板级 / 教科书级别 / 现象级（口语可留一个，别连用）

**改法**：把"赋能实体经济"改成它到底做了什么业务、给谁供货、占营收多少。宣传腔的解药永远是具体数字和具体动作。

## 三、科普区软起手式（删掉，直接进内容）

这类"我要开始讲课了"的报幕，删掉直接说结论：

- 掰开了揉碎了 / 掰扯清楚 / 拆解一下 / 我们来盘一盘 / 你品，你细品
- 让我们来看看 / 接下来我要说的这一点很重要 / 划重点了 / 敲黑板
- 自问自答老师腔："这说明什么？这说明……""为什么会这样？因为……"——把设问删掉，直接陈述结论

> **重要例外（别误杀）**：本 skill 的首选开场是"**先说结论**：……"，这是留住前 5 秒的正规打法，**不在禁用之列**。禁的是"掰开揉碎/你品一下/敲黑板"这类软套话，不是"先说结论"这个开门见山的动作。开场品牌锚、结尾价值锚那两句固定语同理，一字不动。

## 四、高频堆叠副词（一段内重复即删到一处）

AI 爱用副词堆情绪，真人不会一段话里"稳稳""仿佛""瞬间"连着上：

- 稳稳 / 仿佛 / 瞬间 / 紧接着 / 猛地 / 死死 / 狠狠 / 极其 / 极度 / 徐徐 / 缓缓

**判断法**：同一段里同类副词出现两次以上，删到只剩最必要的一处。多数情况整段一个都不留反而更干净。

## 五、"不是 A，而是 B"三毒

这是中文 AI 最标志性的句式，财经稿高发（"跌的不是股价，而是信心""重要的不是涨跌，而是认知"）。完整判定与修法见 [script-structure.md](script-structure.md) 手艺层后的「AI 味句式护栏」专节。一句话记法：**删了前半句意思不损失 → 直接删；A 和 B 是一个意思 → 合并成一句；真有区分（如"我看空的不是公司，而是现在这个价"）→ 保留。**

## 六、这张表和"手艺层""合规红线"的分工

- **合规红线**（SKILL.md）：管违规词——必涨、稳赚、闭眼买、目标价、建仓位。踩了是法律/平台风险。
- **这张 AI 味表**：管机器腔——套话、大词、堆副词、三毒。踩了是质量问题、读着假。
- **手艺层**（script-structure.md）：管有没有魂——具体的人、敢下判断的我、能成像的意象。这是正向要求，词表是反向护栏，配合着用。

三者一起过，稿子才既合规、又不 AI、又有魂。
