# 分镜规划方法论（阶段四 · 花生 AI storyboard_plan.md）

封面定稿后，把这支视频的定稿口播稿翻译成花生 AI 能直接吃的分镜规划书 `storyboard_plan.md`，交花生自动成片。本文件是这一步的完整判断逻辑：方案固定 + 成片需求（含 MG 画风设计）+ Method B 五步 + 输出模板。**严格照此产出，别自由发挥。**

## A. 定位与触发

- **触发时机**：阶段三封面两版成图都出来、用户确认标题之后，自动跑（不新增人工停顿）。
- **输入（三样，都在该视频文件夹里）**：
  1. `视频基础信息.md` 第一节「口播稿」——**唯一真源**，是要被切分的正文。
  2. `视频基础信息.md` 第四节「封面」——设计说明与情绪方向，用来对齐 MG 画风的情绪偏移，并提取本期视觉母题（见 §F）。
  3. `视频基础信息.md` 元信息头——拿股票名、最终标题。
- **产物**：同目录 `storyboard_plan.md` 一个文件。
- **A Roll 输入判定（可选第四输入，决定画面类型是三档还是五档）**：默认本账号无真人出镜、全 `cloud_only`，走标准三档（`b-roll` / `b-roll+mg` / `mg_frame`）。**仅当用户明确声明本片有 A Roll 输入**（如「这支我要露脸拍」「有主播真人口播素材」「加 A Roll」）时，才**附加读取** [storyboard-plan-aroll.md](storyboard-plan-aroll.md)，在三档之外启用 `a-roll` / `a-roll+mg` 两档，并按其方法论判定哪些分镜露脸。**用户没提 A Roll，就当没有**——不自作主张加露脸镜，照常全 `cloud_only` 三档产出。

### A.1 独立入口 / 无封面降级（外来稿直接做视频）

本步不一定从走完阶段一~三的 `视频基础信息.md` 进入。用户拿一份**现成口播稿**（本 skill 之外写的、或从别处拿来的文档）直接说「把这份稿做成分镜」时，也从这一步单独进：

- **唯一硬输入是那份口播稿正文**——它替代上面「第一节口播稿」当唯一真源，逐字照切、绝不改字。股票名/标题若稿里没有，就从正文提炼或问用户一句，别硬编。
- **没有封面时走「无封面降级」**（上面「第四节封面」这个输入缺席）：唯一受影响的是 MG 视觉母题与情绪偏移——**视觉母题不再「沿用封面核心意象」，改为直接从稿子主体（公司/行业/核心论点）提炼一个**（提炼方法见 §F，只是换个来源，不换规则）；情绪温度偏移从稿子本身的多空判断取。**其余（方案 B 固定、Method B 五步、三档逻辑、cloud_only、输出模板）全部照常，不受影响。**
- **落地位置**：有 `视频基础信息.md` 就照常同目录落 `storyboard_plan.md` + 补指针小节；走独立入口没有该文档时，直接把 `storyboard_plan.md` 落在来源稿同目录（或用户指定目录），不强行补建整套文档。

## B. 方案固定：B 素材混合 MG 动画

蛋炒饭财经是数据/观点密集的财经解说，画面天然是「实拍素材 B-roll 为主 + 关键处叠加/框架 MG」，**恒定走方案 B「素材混合 MG 动画」**，不需要问用户选 A 还是 B（producer 那一步的方案选择在本账号语境里省略）。本账号**没有本地素材库**，所有分镜 `source` 一律 `cloud_only`。

## C. 成片需求（含 MG 画风设计）· 财经精简版

`storyboard_plan.md` 第一节写这份成片需求，字段照下面填（砍掉了故事类视频才用的字段）：

- **📋 基础信息**
  - 视频标题：= 用户定稿的最终标题
  - 内容摘要：100-150 字，一段视频简介级别的话，讲清这条视频的核心判断
  - 年代背景：财经视频默认「2026年 · 现代」（除非稿子主体是讲某段历史行情）
  - 制作方案：固定「B 素材混合 MG 动画」
  - 参考风格：严肃财经调查 / 深度解说类 UP 主风格
  - BGM 需求：一句自然语言描述，贴合稿子情绪（看跌沉稳压抑 / 看涨明快有张力 / 中性理性克制）
- **🎥 素材要求**
  - 素材类型：新闻资料、财报截图、公司厂区/门店空镜、产品实拍、发布会画面等，列主要几类
  - 素材偏好：数据类画面留白给 MG 叠加；避免素人正脸；镜头偏硬朗、审视感
  - 素材禁忌（硬规则）：**不检索「K 线走势图」「个股行情图」，也不把「具体股价数字」当检索素材**——检索系统对不上具体股票和具体时段，拿到的必然是一张错的 K 线、错的价格。走势、涨跌、股价数字一律改由 MG 动画绘制（`b-roll+mg` / `mg_frame`），别指望实拍/资料图能「找到正确的那根 K 线」。
  - 时效性：使用 2025 年后的近期素材（涉及行情、产品、公司现状）
  - 地域限定：中国（A 股公司默认；港美股按实际）
  - 专名要求：素材中应出现的公司中文名（如「贵州茅台」）+ 核心产品名
  - 用户硬性要求：原文转述用户提的硬性要求与禁忌（若无则写「无」），最高优先级
- **🎨 MG 动画风格**（双层模型：账号固定基因 × 本期内容共振，见 §F）
  - 固定基因（永不变）：严肃财经调查 / 硬朗商务；炭灰墨黑底 + 暖金点缀色板；标题极粗黑体、数字用数字展示体、正文硬朗黑体；图标庄重（Serious）。这是「一眼认出蛋炒饭财经」的骨架。
  - 情绪温度偏移：在不换色板的前提下按稿子情绪微调（看涨偏 40 加暖红 / 看跌压暗加警示黄 / 中性炭灰加金居中）。
  - **视觉母题（本期共振层）**：从本期公司/行业/核心论点提炼**一个**具象母题，作为 MG 的辅助纹理 / 转场元素 / 点缀灵感来源，贯穿全片，让观众感到「风格和这次讲的内容有关」。**优先沿用封面已提炼的核心意象**，保证封面→成片连贯；不改主色板与主字体，不喧宾夺主。举例：白酒→酒液琥珀色泽/酒瓶轮廓/蓄水池水位；芯片→晶圆电路/晶格；新能源→电流/电芯格；医药→分子/试管结构。用一句话写清母题是什么、怎么用。

紧跟一段机读 `global_style`（花生取值参考，具体枚举值受花生资产库约束，取列表内最接近项，实测校准）：

```json
{
  "visual_style": "取花生视觉风格列表中最接近『严肃财经调查/硬朗商务』的项",
  "color_system": { "color_style": "取深色/浓郁系", "main_hsb_hue": 45 },
  "typography": {
    "title_font": { "font_family": "极粗黑体（如得意黑一类）", "font_weight": "black" },
    "body_font":  { "font_family": "硬朗黑体", "font_weight": "regular" },
    "number_font":{ "font_family": "带『数字展示』标签的字体", "font_weight": "semibold" }

```

> `main_hsb_hue` 取暖金 40-50（对齐封面「炭灰+暖金」，也落在金融题材 30-50 区间）。看涨可偏 40 加暖红、看跌压暗、中性居中，都在暖金内调温度。`global_style` 只承载固定基因；视觉母题是自然语言层的东西，写在 🎨 字段和各 MG 分镜的画面描述里，不塞进这段 JSON。

## D. Method B 五步（画面类型下沉到分镜 · 场景只是检索批次）

**粒度总则：画面是分镜的属性，不是场景的属性。** 一支财经解说里，一段连续叙事（例如「讲牧原成本倒挂」）内部往往是这样的真实形态：平陈述（该 `b-roll`）→ 砸一个成本数字（该 `b-roll+mg`）→ 继续背景（`b-roll`）。画面价值的触发点是**「这一刻 / 这一句」**级的，落在分镜上；把整段贴一个类型，要么把不该上 MG 的铺陈句糊满动效（廉价堆砌），要么把该砸屏的数字埋进纯实拍（钩子丢掉）。所以：

- **画面类型（`b-roll` / `b-roll+mg` / `mg_frame`）定在分镜，一镜一给。**
- **画面描述也定在分镜**——因为描述本就依附于类型（是 b-roll 就写配什么实拍，是 b-roll+mg 就写叠加什么）。
- **场景退化成「素材检索批次」**——一段共享同一批检索上下文的连续叙事，唯一的活是给下游检索一份共享的「素材要求」，不背画面类型、不背画面描述。

动笔前先按三层拆稿看清每段在干什么：**内容层**（客观事实、新闻、行情陈述）、**认知层**（观点/数据/逻辑分析）、**结构层**（开头钩子/转场/收尾）。这三层是帮你在分镜上判断「画面价值」的镜头。

### 步骤一：场景划分（素材检索批次）

**场景 = 一个素材检索批次**，不是画面单元。通读全稿，把连续、共享同一批检索上下文的叙事归为一个场景。

- **切场景的充分条件**（满足任一才切）：**叙事主体切换**（换一家公司 / 换一个论点主体）/ **素材来源切换**（从财报截图转到猪场实拍、从 K 线转到评论区）。
- **不该切**：画面在变、情绪在变，但检索的还是同一批素材——不切。画面与情绪的起伏交给分镜层的画面类型去表达，别拿它切场景。
- **不再为「隔离一个数字」硬切小场景**——那个数字的强调由所在分镜升级成 `b-roll+mg` 解决，与场景无关。这条正是旧粒度最大的毛病，务必戒掉。
- **场景长度**：一个检索批次通常 100~300 字，不设硬上限；真正的硬约束是**每场景最多 10 个分镜**（超了拆成两个场景）。
- **编号**：A01、A02…，每场景一个简短 `scene_title`（标注它是哪批素材的批次，如「成本倒挂·猪场实拍」）。

### 步骤二：场景素材要求（scene_design）

每个场景一段，是给下游检索服务的「检索执行摘要」（下游看不到全稿），换行拼成一段。四要素：

- **专名清单**：列场景内专名，格式 `专名（类型）`，人名 > 品牌 > 地标 > 作品名，顿号分隔；代词消歧 `"代词"→专名`；**公司中文名必须在这里出现**。无则写「无」。
- **国家、年代**：`国家：中国 / 年代：现代`（按实际，台湾不填国家字段）。
- **素材来源**：具体作品名/资料类型（如「财报发布会实录、酒厂车间纪录片」）；泛泛的「财经素材」不算。**禁止写 K 线走势图 / 个股行情图 / 具体股价**——这些检索对不上（拿到的是别的股票、别的时段的图），走势与数字改由 MG 画。
- **素材偏好**：镜头/风格偏好 + 禁忌，如「数据画面留白给 MG，避免素人正脸」。

### 步骤三：分镜断句（Shot）+ source

对每个场景，把它那段口播切成分镜。

**首要准则：一个分镜 = 一个完整独立的画面 + 一段自足的语义。** 切分镜的问题不是「这里有没有标点」，而是「**这一句念出来，脑子里换不换一个新画面 / 是不是一个能独立成立的意思**」。换画面、进入一个新的独立意思，才切下一镜；同一个画面、同一个意思的延续（哪怕跨了逗号、跨了句号）就留在一镜里。宁长勿碎——碎的分镜会让画面频繁跳切、语义悬空。

- **判断切点**：问「下一句是不是要换画面 / 起一个新的独立意思」——是则切，否则并入本镜。因果、转折、并列这些**为同一个意思服务**的复合结构，整体留在一镜；一个数字+它的解读、一个名词+它的定义，都算一个自足语义单元，不拆开。
- **字数是护栏不是依据**（不含标点，只算念出来的字）：
  - `b-roll` / `b-roll+mg` 分镜：一个自足画面通常 **15~50 字，平均 30 字上下**。<12 字且语义不自足 → 与相邻同画面分镜合并；>50 字 → 多半塞了两个画面/两个意思，在画面切换点拆两镜（不是硬凑字数去切）。
  - **`mg_frame` 分镜是例外，可以更长（60~120 字）**：它本身就是一个装了一整段时序/对比的框架画面——框架恒在屏上，几份素材作视窗依次弹出，口播天然更长。这不叫「塞了两个画面该拆」，它就是**一个画面**。只有当一个框架实在装不下（要素超多、逻辑分岔）时才拆成两个 `mg_frame`。
- **数量**：不设下限，一个场景该切几镜由「一镜=一个独立画面+自足语义」决定；**唯一硬约束是每场景最多 10 个分镜**。拆完 >10 个 → 回步骤一把这个场景细拆成两个场景。
- **编号**：S01、S02…（全篇顺序）。
- **source**：本账号无本地素材库，**所有分镜 `source` 一律 `cloud_only`**。
- **完整性约束**：分镜 script 只能从口播稿原文「切」出来——不遗漏、不新增、不改任何一个字或标点（花生逐字照念，见 §A）。合并/断句只改「在哪里切」，绝不改字；写作时逐句原样搬即可，交付前不必再拼接比对。

### 步骤四：分镜画面类型判定（三档价值逻辑）

**画面类型定在分镜。** 每个分镜由你依据下面的**观看价值逻辑**给一档。拿不准时问自己一句：**「这一镜如果只用实拍，观众会不会看不懂、或者觉得平而划走？」**——会，就升级。

三种画面本质是**素材编排强度的三档**——从「单素材铺满全屏、自己连续播」，到「单素材作底板+叠加一层 MG」，再到「一个画面装不下、多个素材被编排进一个框架」。落哪一档，核心问一句：**这一镜、这一刻，单一素材能不能自我陈述？** 能，就 `b-roll`；素材本身够用、但要砸个重点或画条逻辑上去，就 `b-roll+mg`；一个画面装不下——素材要并排陈列、要快切、要成组拎出来强调——就 `mg_frame`。

三种画面各自的观看价值与触发场景：

- **`b-roll` 纯素材 —— 真实感与呼吸**
  - 价值：提供事实背景、情绪铺垫、节奏留白，制作成本最低，是全片底色。
  - 用在：客观事实陈述、新闻背景、公司/产品实拍、开场白铺陈、情感过渡、故事化叙述。
  - 风险：连续堆太多→画面平、信息密度低→观众划走（见节奏原则）。

- **`b-roll+mg` 素材叠加 MG —— 把关键信息「砸」到眼前 + 把抽象逻辑「画」出来**
  - 价值：让数字/名词/观点「看得见」，把观众注意力锁在真正重要的那个点上，同时抬升信息密度与制作精致感。实拍暗化/虚化作底板，上叠动态数字、柱状图、名词卡片、大字报、箭头/流程示意。**它也是复杂逻辑概念的轻量呈现手段**——当一句话讲的是抽象机制、因果链、传导关系时，光靠实拍观众抓不住，配一层简单示意图（箭头传导、要素连线、正负号、简化流程）就能瞬间说清；这类「单点抽象概念图解」优先用 `b-roll+mg`，只有当逻辑要素多、需要一个统一框架统摄全局时才升级到 `mg_frame`。
  - 升级信号（满足任一就上）：① 出现需要被记住的**具体数字**（营收、增速、占比、价格）——数字要动态砸屏；② 首次出现、需即时解释的**专业名词**（合同负债、批价）；③ **核心金句 / 强观点 / 态度吐槽**——需要放大情绪；④ 单一对比、两三步的**简单因果或流程**；⑤ **单点抽象逻辑/机制**——一个概念、一条传导链、一组因果关系，纯口播偏抽象、配张简单示意图就懂的（要素多到需要整体框架的走 `mg_frame`）。

- **`mg_frame` 框架 MG —— 一个信息高密度的长分镜**
  - 本质：它是**一个素材容器画面**——一个统一框架（时间轴、多宫格、分屏、拓扑图）恒在屏上，几份素材（视频素材、联网图、生图）作视窗在框内并排陈列 / 成组快切 / 依次弹出。它就是**一个画面、一个偏长的分镜**（不是一个场景、不横跨多个分镜）；正因为要在这一个画面里讲完一段时序或一组对比，它的口播天然更长（60~120 字）。它也是全片的「精致度天花板」，放在关键位置能显著拉高第一印象、降低跳出，是最「贵」的画面。
  - 升级信号分两类，任一成立即为候选：
    - **素材价值（编排需求驱动，最核心的判断）**：① **多素材并排陈列**——这一镜要同时给出几份素材（几家公司、几个节点、几张图），单画面一次只装得下一个，必须用框摆进同一帧；② **素材成组快切**——一串素材要高速切换（连报数据、几个场景闪过），裸切会散会晕，用固定框把节奏框住才稳；③ **拎出某一类画面强调**——一个关键数字、一张核心图要放大高亮、跳出叙事流，给它专属位置与权重。
    - **位置价值（观看曲线驱动）**：① **开场钩子**（前 15~20 秒）——优先安排一个 `mg_frame` 或强 `b-roll+mg`，用高密度 + 高级感在黄金几秒抓住人、把跳出率压下去；② 全片 **1~2 个「信息高潮」**——最核心、最复杂的那段论证；③ **收尾的清单/信号/行动指南**——结构化收束，做记忆点。
    - 上面这些落到「信息结构」上，常见形态是：多案例/多公司**横向对比**、长**时间轴/多阶段演进**、抽象**机制拆解**（拓扑/流程/分层图）、强**并列清单**——但判断时先想「素材扛不扛得住」，形态只是结果。
  - 反例（别硬上）：素材单一且能自我陈述（一条连续的车间/猪场空镜、一个完整动作）、走情绪氛围的铺垫段、顺着讲不需要多素材的口播流水句——加框是画蛇添足，交给 `b-roll` 或 `b-roll+mg`。

**节奏原则（贯穿全片，定完类型回头扫一遍分镜序列）**

- MG 服务于「该强调的地方」，不是越多越好；密度过高→廉价堆砌感、观众疲劳。
- 分布呈**「两头重、中间点缀」**：开场与收尾舍得上 MG，中间以 `b-roll` 为底、每隔一段用一个 `b-roll+mg` 提神，**避免连续 4 个以上 `b-roll` 分镜堆在一起**（这条现在按分镜数，不再按场景数——粒度下沉后才准）。
- 建议判定顺序：先按位置价值锁定「开场 / 信息高潮 / 收尾」的 `mg_frame` 或强 `b-roll+mg` → 再扫全稿逐镜标出该强调的数字/名词/金句给 `b-roll+mg` → 其余默认 `b-roll`。

### 步骤五：分镜画面描述（依画面类型，逐镜写）

每个分镜一段画面描述，依它的类型写（这就是为什么描述要跟着类型一起下沉到分镜）。MG 类画面本质是「底 + 层」的双层结构——底下垫一层素材、上面压一层 MG（或框），**两层都要交代清楚，别只写 MG 那层动效、漏了底下垫什么素材**。

- `b-roll`：写这一镜该配什么实拍画面（花生按此检索），一句话说清「什么内容 + 什么镜头感」。

- `b-roll+mg`：这是「单素材底板 + 叠加一层 MG」的双层画面，描述分两层写：
  - **底板素材（先写）**：这镜底部垫什么实拍/资料画面最合适——写清素材是什么（如「工厂车间全景空镜」「财报发布会截图」）、画面内容与镜头感。若口播是递进/对比关系、底部需要**两个递进式素材**（前一个铺垫、后一个落点），就**分别描述这两个视频素材各自是什么**，并说清二者的衔接关系（先后递进、正反对照）。
  - **MG 叠加层（再写）**：叠加在底板上的 MG 动画整体内容（动态数字、柱状图、名词卡片、大字报、箭头/流程示意）、动效（数字从 0 滚到目标值、柱状图逐条高亮、箭头生长、正负号闪烁）、以及与口播的配合节奏（念到哪句词砸哪个数字、何时放大、何时收）。
  - 例：「底为财报发布会截图暗化作衬；上方柱状图逐条高亮，同比增速数字从 0 滚到 +21%，念到『利润翻倍』时整组数字放大定格。」

- `mg_frame`：这是「一个统一框架 + 多份素材作视窗嵌入」的画面，描述分三块写：
  - **底层视觉框架设计**：这镜的整体框架长什么样——时间轴、多宫格面板、分屏、拓扑/流程/分层图……写清框架的结构、排布、视觉语言（哪几格、什么走向、母题纹理点缀）。
  - **素材如何嵌入**：在框架的**哪个位置**、按**什么顺序**弹出什么素材的视窗（哪个节点弹哪张图、第几格放哪家公司、从左到右依次还是并排常驻、快切还是依次弹出）。
  - **嵌入的素材是什么**：每个视窗里嵌的素材**具体是什么样的素材**（视频素材 / 联网图 / 生图 / 实拍空镜 / 截图），逐一说清它的画面内容，别只写「放一张图」。
  - 例：「四宫格框架炭灰底 + 暖金分割线：左上恒瑞（生图·药企大楼），右上百济神州（生图·研发中心），下方两张依次弹出对应管线进度时间轴；念到哪家，哪一格金框高亮、其余压暗。」

- **共振层带入**：MG 类分镜（`b-roll+mg` / `mg_frame`）的描述里，**自然带进本期视觉母题**（§F）——作为底纹、点缀、转场或图标灵感，别硬塞，别盖掉主色板与主字体。

## F. MG 画风双层模型：账号固定基因 × 本期内容共振

蛋炒饭财经的 MG 视觉要同时做到两件事——**让观众一眼认出「这就是蛋炒饭财经」**，又**能感到「这套风格和这期讲的内容有关」**。所以把 MG 画风拆成两层：

**① 固定层 · 账号基因（永不变，是识别度骨架）**

账号封面基因已锁定（见 `workspace/huasheng.md` 封面章节）：**严肃财经调查风、墨黑/炭灰 + 暖金主色板、极粗黑体标题、数字展示体、Serious 图标、硬朗审视的构图、克制有重量感的动效**。每期成片这套骨架原样套用，不换色板、不换主字体、不换图标风格。这是系列识别度的来源。

**② 共振层 · 本期视觉母题（每期变，是内容适配）**

在固定骨架之上，为本期提炼**一个具象「视觉母题」**——一个能代表这支视频主体的意象/纹理/符号，作为 MG 的辅助纹理、转场元素、点缀色来源或图标灵感，贯穿全片。它让观众下意识觉得画面「长得像这次的内容」，但不动主色板与主字体，不喧宾夺主。

- **怎么提炼**：从本期公司 / 行业 / 核心论点里找一个最有代表性的具象符号或隐喻。**优先直接沿用封面里已经用到的核心意象**——封面往往已经提炼过一个视觉符号，成片沿用它，封面→成片就是连贯的一套。**走无封面降级（独立入口、无封面输入，见 §A.1）时**：没有封面意象可沿用，直接从稿子主体（公司/行业/核心论点）提炼一个母题即可——方法一样，只是来源从「封面」换成「稿子」，其余规则不变。
  - 白酒 → 酒液琥珀色泽 / 酒瓶轮廓 / 蓄水池水位（呼应「挤水分」这类论点）
  - 芯片半导体 → 晶圆电路 / 晶格网格 / 引脚
  - 新能源 → 电流脉冲 / 电芯格 / 充放电波形
  - 医药 → 分子结构 / 试管 / 心电波
  - 银行地产 → 资金流水 / 砖块楼宇剪影
- **怎么落地**：作为 MG 的底纹、分割线、转场动画、数据图形的形状语言或点缀图标，弱处理、不抢主信息；写进 🎨 字段一句话（是什么 + 怎么用），并在各 MG 分镜（`b-roll+mg` / `mg_frame`）的画面描述里自然带进去。

**③ 情绪温度偏移（共振层的一部分）**

在不换色板的前提下按本条稿子的多空情绪调温度：

- 看涨稿：暖金偏 40 + 少量暖红，明快有张力
- 看跌稿：压暗、加警示黄，沉稳有压迫感
- 中性稿：炭灰 + 暖金居中，理性克制

字体、图标固定：标题极粗黑体、数字数字展示体、图标 Serious。花生 `global_style` 的具体枚举值受其资产库约束，取列表内最接近「严肃财经调查/硬朗商务」的项，首次实测后校准记录。
