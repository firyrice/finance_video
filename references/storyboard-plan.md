# 分镜规划方法论（阶段四 · 花生 AI storyboard_plan.md）

封面定稿后，把这支视频的定稿口播稿翻译成花生 AI 能直接吃的分镜规划书 `storyboard_plan.md`，交花生自动成片。本文件是这一步的完整判断逻辑：方案固定 + 成片需求（含 MG 画风设计）+ Method B 五步 + 输出模板。**严格照此产出，别自由发挥。**

## A. 定位与触发

- **触发时机**：阶段三封面两版成图都出来、用户确认标题之后，自动跑（不新增人工停顿）。
- **输入（三样，都在该视频文件夹里）**：
  1. `视频基础信息.md` 第一节「口播稿」——**唯一真源**，是要被切分的正文。
  2. `视频基础信息.md` 第四节「封面」——设计说明与情绪方向，用来对齐 MG 画风的情绪偏移，并提取本期视觉母题（见 §F）。
  3. `视频基础信息.md` 元信息头——拿股票名、最终标题。
- **产物**：同目录 `storyboard_plan.md` 一个文件。

## B. 方案固定：B 素材混合 MG 动画

蛋炒饭财经是数据/观点密集的财经解说，画面天然是「实拍素材 B-roll 为主 + 关键处叠加/框架 MG」，**恒定走方案 B「素材混合 MG 动画」**，不需要问用户选 A 还是 B（producer 那一步的方案选择在本账号语境里省略）。本账号**没有本地素材库**，所有分镜 `source` 一律 `cloud_only`。

## C. 成片需求（含 MG 画风设计）· 财经精简版

`storyboard_plan.md` 第一节写这份成片需求，字段照下面填（砍掉了故事类视频才用的字段）：

- **📋 基础信息**
  - 视频标题：= 用户定稿的最终标题
  - 内容摘要：100-150 字，一段视频简介级别的话，讲清这条视频的核心判断
  - 年代背景：财经视频默认「2026年 · 现代」（除非稿子主体是讲某段历史行情）
  - 制作方案：固定「B 素材混合 MG 动画」
  - 参考风格：严肃财经调查 / 深度解说类 UP 主风格
  - BGM 需求：一句自然语言描述，贴合稿子情绪（看跌沉稳压抑 / 看涨明快有张力 / 中性理性克制）
- **🎥 素材要求**
  - 素材类型：新闻资料、财报截图、K 线走势、公司厂区/门店空镜、产品实拍、发布会画面等，列主要几类
  - 素材偏好：数据类画面留白给 MG 叠加；避免素人正脸；镜头偏硬朗、审视感
  - 时效性：使用 2025 年后的近期素材（涉及行情、产品、公司现状）
  - 地域限定：中国（A 股公司默认；港美股按实际）
  - 专名要求：素材中应出现的公司中文名（如「贵州茅台」）+ 核心产品名
  - 用户硬性要求：原文转述用户提的硬性要求与禁忌（若无则写「无」），最高优先级
- **🎨 MG 动画风格**（双层模型：账号固定基因 × 本期内容共振，见 §F）
  - 固定基因（永不变）：严肃财经调查 / 硬朗商务；炭灰墨黑底 + 暖金点缀色板；标题极粗黑体、数字用数字展示体、正文硬朗黑体；图标庄重（Serious）。这是「一眼认出蛋炒饭财经」的骨架。
  - 情绪温度偏移：在不换色板的前提下按稿子情绪微调（看涨偏 40 加暖红 / 看跌压暗加警示黄 / 中性炭灰加金居中）。
  - **视觉母题（本期共振层）**：从本期公司/行业/核心论点提炼**一个**具象母题，作为 MG 的辅助纹理 / 转场元素 / 点缀灵感来源，贯穿全片，让观众感到「风格和这次讲的内容有关」。**优先沿用封面已提炼的核心意象**，保证封面→成片连贯；不改主色板与主字体，不喧宾夺主。举例：白酒→酒液琥珀色泽/酒瓶轮廓/蓄水池水位；芯片→晶圆电路/晶格；新能源→电流/电芯格；医药→分子/试管结构。用一句话写清母题是什么、怎么用。

紧跟一段机读 `global_style`（花生取值参考，具体枚举值受花生资产库约束，取列表内最接近项，实测校准）：

```json

  "visual_style": "取花生视觉风格列表中最接近『严肃财经调查/硬朗商务』的项",
  "color_system": { "color_style": "取深色/浓郁系", "main_hsb_hue": 45 },
  "typography": {
    "title_font": { "font_family": "极粗黑体（如得意黑一类）", "font_weight": "black" },
    "body_font":  { "font_family": "硬朗黑体", "font_weight": "regular" },
    "number_font":{ "font_family": "带『数字展示』标签的字体", "font_weight": "semibold" }
  },

```

> `main_hsb_hue` 取暖金 40-50（对齐封面「炭灰+暖金」，也落在金融题材 30-50 区间）。看涨可偏 40 加暖红、看跌压暗、中性居中，都在暖金内调温度。`global_style` 只承载固定基因；视觉母题是自然语言层的东西，写在 🎨 字段和各场景 `mg_description` 里，不塞进这段 JSON。

## D. Method B 五步（财经约束版）

动笔前先按三层拆稿看清每段在干什么：**内容层**（客观事实、新闻、行情陈述）、**认知层**（观点/数据/逻辑分析）、**结构层**（开头钩子/转场/收尾）。这三层是帮你判断「画面价值」的镜头，具体画面类型怎么给见步骤一。

### 步骤一：场景划分（Scene）+ 画面类型判定

**场景 = 一个独立的叙事单元，像视频里的一个章节。** 通读全稿，切成连续的大段叙事单元，再给每个场景定画面类型。

**（1）切场景**

- **切场景的充分条件**（满足任一才切）：画面场景根本变化 / 素材来源切换 / 叙事主体切换 / 情绪基调大幅转变。
- **不该切**：仅论点递进（原因一→二→三）或细节补充，属同一叙事单元，不拆。
- **场景文案长度**：常规场景（`b-roll`/`b-roll+mg`）口播 100~250 字；框架场景（`mg_frame`）逻辑要极强的整体性（连续时序/横向对比），口播 80~120 字。
- **编号**：A01、A02…（大段顺序）。每个场景一个简短 `scene_title`。

**（2）画面类型判定**

每个场景的画面类型（`b-roll` / `b-roll+mg` / `mg_frame`）由你依据下面的**观看价值逻辑**直接给定。拿不准时问自己一句：**「这一段如果只用实拍，观众会不会看不懂、或者觉得平而划走？」**——会，就升级。

三种画面本质是**素材编排强度的三档**——从「单素材铺满全屏、自己连续播」，到「单素材作底板+叠加一层 MG」，再到「一个画面装不下、多个素材被编排进一个框架」。落哪一档，核心问一句：**这一刻单一素材能不能自我陈述？** 能，就 `b-roll`；素材本身够用、但要砸个重点或画条逻辑上去，就 `b-roll+mg`；一个画面装不下——素材要并排陈列、要快切、要成组拎出来强调——就 `mg_frame`。

三种画面各自的观看价值与触发场景：

- **`b-roll` 纯素材 —— 真实感与呼吸**
  - 价值：提供事实背景、情绪铺垫、节奏留白，制作成本最低，是全片底色。
  - 用在：客观事实陈述、新闻背景、公司/产品实拍、开场白铺陈、情感过渡、故事化叙述。
  - 风险：连续堆太多→画面平、信息密度低→观众划走（见节奏原则）。

- **`b-roll+mg` 素材叠加 MG —— 把关键信息「砸」到眼前 + 把抽象逻辑「画」出来**
  - 价值：让数字/名词/观点「看得见」，把观众注意力锁在真正重要的那个点上，同时抬升信息密度与制作精致感。实拍暗化/虚化作底板，上叠动态数字、柱状图、名词卡片、大字报、箭头/流程示意。**它也是复杂逻辑概念的轻量呈现手段**——当一句话讲的是抽象机制、因果链、传导关系时，光靠实拍观众抓不住，配一层简单示意图（箭头传导、要素连线、正负号、简化流程）就能瞬间说清；这类「单点抽象概念图解」优先用 `b-roll+mg`，只有当逻辑要素多、需要一个统一框架统摄全局时才升级到 `mg_frame`。
  - 升级信号（满足任一就上）：① 出现需要被记住的**具体数字**（营收、增速、占比、价格）——数字要动态砸屏；② 首次出现、需即时解释的**专业名词**（合同负债、批价）；③ **核心金句 / 强观点 / 态度吐槽**——需要放大情绪；④ 单一对比、两三步的**简单因果或流程**；⑤ **单点抽象逻辑/机制**——一个概念、一条传导链、一组因果关系，纯口播偏抽象、配张简单示意图就懂的（要素多到需要整体框架的走 `mg_frame`）。

- **`mg_frame` 框架 MG —— 用一个框架编排多个素材 + 制造高级感**
  - 本质：它是个**素材容器**。当**一个镜头装不下这一刻要给的东西**时，用一个统一框架（时间轴、多宫格、分屏、拓扑图）把多份素材（视频素材、联网图、生图）编排进同一帧——并排陈列、成组快切、或把某一类画面拎出来放大强调。视窗内嵌入实拍。它也是全片的「精致度天花板」，放在关键位置能显著拉高第一印象、降低跳出，是最「贵」的画面。
  - 升级信号分两类，任一成立即为候选：
    - **素材价值（编排需求驱动，最核心的判断）**：① **多素材并排陈列**——这一刻要同时给出几份素材（几家公司、几个节点、几张图），单镜头一次只装得下一个，必须用框摆进同一帧；② **素材成组快切**——一串素材要高速切换（连报数据、几个场景闪过），裸切会散会晕，用固定框把节奏框住才稳；③ **拎出某一类画面强调**——一个关键数字、一张核心图要放大高亮、跳出叙事流，给它专属位置与权重。
    - **位置价值（观看曲线驱动）**：① **开场钩子**（前 15~20 秒）——优先安排一个 `mg_frame` 或强 `b-roll+mg`，用高密度 + 高级感在黄金几秒抓住人、把跳出率压下去；② 全片 **1~2 个「信息高潮」**——最核心、最复杂的那段论证；③ **收尾的清单/信号/行动指南**——结构化收束，做记忆点。
    - 上面这些落到「信息结构」上，常见形态是：多案例/多公司**横向对比**、长**时间轴/多阶段演进**、抽象**机制拆解**（拓扑/流程/分层图）、强**并列清单**——但判断时先想「素材扛不扛得住」，形态只是结果。
  - 反例（别硬上）：素材单一且能自我陈述（一条连续的车间/猪场空镜、一个完整动作）、走情绪氛围的铺垫段、顺着讲不需要多素材的口播流水句——加框是画蛇添足，交给 `b-roll` 或 `b-roll+mg`。

**（3）节奏原则（贯穿全片，定完类型回头扫一遍）**

- MG 服务于「该强调的地方」，不是越多越好；密度过高→廉价堆砌感、观众疲劳。
- 分布呈**「两头重、中间点缀」**：开场与收尾舍得上 MG，中间以 `b-roll` 为底、每隔一段用一个 `b-roll+mg` 提神，**避免连续 4 个以上 `b-roll` 场景堆在一起**。
- 建议判定顺序：先按位置价值锁定「开场 / 信息高潮 / 收尾」的 `mg_frame` 候选 → 再扫全稿标出该强调的数字/名词/金句给 `b-roll+mg` → 其余默认 `b-roll`。

### 步骤二：场景内分镜断句（Shot）

对每个场景，把它那段口播切成分镜。

**首要准则：一个分镜 = 一个完整独立的画面 + 一段自足的语义。** 切分镜的问题不是「这里有没有标点」，而是「**这一句念出来，脑子里换不换一个新画面 / 是不是一个能独立成立的意思**」。换画面、进入一个新的独立意思，才切下一镜；同一个画面、同一个意思的延续（哪怕跨了逗号、跨了句号）就留在一镜里。宁长勿碎——碎的分镜会让画面频繁跳切、语义悬空。

- **判断切点**：问「下一句是不是要换画面 / 起一个新的独立意思」——是则切，否则并入本镜。因果、转折、并列这些**为同一个意思服务**的复合结构，整体留在一镜；一个数字+它的解读、一个名词+它的定义，都算一个自足语义单元，不拆开。
- **字数是护栏不是依据**（不含标点，只算念出来的字）：一个自足画面通常落在 **15~50 字，平均 30 字上下**。
  - 拆完发现某镜 <12 字且语义不自足 → 与相邻同画面分镜合并。
  - 某镜 >50 字 → 多半是塞了两个画面/两个意思，回头看能不能在画面切换点拆成两镜（不是硬凑字数去切）。
  - 落在区间内但画面/语义确实该分的，照分；确实是一个整体的，哪怕略超也别切碎。
- **数量**：不设下限，一个场景该切几镜由「一镜=一个独立画面+自足语义」决定；**唯一硬约束是每场景最多 10 个分镜**。拆完 >10 个 → 回步骤一把这个场景细拆成两个场景。
- **编号**：S01、S02…（全篇顺序）。
- **完整性约束（最硬的一条）**：所有场景所有分镜的 script 顺序拼接后，**必须与第一节口播稿全文逐字一致**——不遗漏、不新增、不改任何一个字或标点。这是财经稿花生照念的红线（见 §A）。合并/断句只改「在哪里切」，绝不改字。

### 步骤三：source（本地素材评估）

本账号无本地素材库，**所有分镜 `source` 一律 `cloud_only`**。

### 步骤四：scene_design（素材要求）

每个场景一段，是给下游检索服务的「检索执行摘要」（下游看不到全稿），换行拼成一段。四要素：

- **专名清单**：列场景内专名，格式 `专名（类型）`，人名 > 品牌 > 地标 > 作品名，顿号分隔；代词消歧 `"代词"→专名`；**公司中文名必须在这里出现**。无则写「无」。
- **国家、年代**：`国家：中国 / 年代：现代`（按实际，台湾不填国家字段）。
- **素材来源**：具体作品名/资料类型（如「财报发布会实录、酒厂车间纪录片、K 线走势」）；泛泛的「财经素材」不算。
- **素材偏好**：镜头/风格偏好 + 禁忌，如「数据画面留白给 MG，避免素人正脸」。

### 步骤五：场景画面描述（mg_description）

- `b-roll`：写这个场景该配什么实拍画面（花生按此检索）。
- `b-roll+mg`：描述叠加层 MG 的整体内容、动效、与口播配合的节奏（如「实拍财报页作底板暗化，上方柱状图逐条高亮，同比数字从 0 滚到目标值」）。
- `mg_frame`：详细描述**底层框架设计**（时间轴/多宫格/拓扑图）+ **素材如何嵌入**（哪个节点弹什么视窗、弹出顺序）。
- **共振层带入**：MG 类场景（`b-roll+mg` / `mg_frame`）的描述里，**自然带进本期视觉母题**（§F）——作为底纹、点缀、转场或图标灵感，别硬塞，别盖掉主色板与主字体。

## 二、分镜脚本（Method B）

### A01 · <场景标题>

## F. MG 画风双层模型：账号固定基因 × 本期内容共振

蛋炒饭财经的 MG 视觉要同时做到两件事——**让观众一眼认出「这就是蛋炒饭财经」**，又**能感到「这套风格和这期讲的内容有关」**。所以把 MG 画风拆成两层：

**① 固定层 · 账号基因（永不变，是识别度骨架）**

账号封面基因已锁定（见 `workspace/huasheng.md` 封面章节）：**严肃财经调查风、墨黑/炭灰 + 暖金主色板、极粗黑体标题、数字展示体、Serious 图标、硬朗审视的构图、克制有重量感的动效**。每期成片这套骨架原样套用，不换色板、不换主字体、不换图标风格。这是系列识别度的来源。

**② 共振层 · 本期视觉母题（每期变，是内容适配）**

在固定骨架之上，为本期提炼**一个具象「视觉母题」**——一个能代表这支视频主体的意象/纹理/符号，作为 MG 的辅助纹理、转场元素、点缀色来源或图标灵感，贯穿全片。它让观众下意识觉得画面「长得像这次的内容」，但不动主色板与主字体，不喧宾夺主。

- **怎么提炼**：从本期公司 / 行业 / 核心论点里找一个最有代表性的具象符号或隐喻。**优先直接沿用封面里已经用到的核心意象**——封面往往已经提炼过一个视觉符号，成片沿用它，封面→成片就是连贯的一套。
  - 白酒 → 酒液琥珀色泽 / 酒瓶轮廓 / 蓄水池水位（呼应「挤水分」这类论点）
  - 芯片半导体 → 晶圆电路 / 晶格网格 / 引脚
  - 新能源 → 电流脉冲 / 电芯格 / 充放电波形
  - 医药 → 分子结构 / 试管 / 心电波
  - 银行地产 → 资金流水 / 砖块楼宇剪影
- **怎么落地**：作为 MG 的底纹、分割线、转场动画、数据图形的形状语言或点缀图标，弱处理、不抢主信息；写进 🎨 字段一句话（是什么 + 怎么用），并在各 MG 场景的 `mg_description` 里自然带进去。

**③ 情绪温度偏移（共振层的一部分）**

在不换色板的前提下按本条稿子的多空情绪调温度：

- 看涨稿：暖金偏 40 + 少量暖红，明快有张力
- 看跌稿：压暗、加警示黄，沉稳有压迫感
- 中性稿：炭灰 + 暖金居中，理性克制

字体、图标固定：标题极粗黑体、数字数字展示体、图标 Serious。花生 `global_style` 的具体枚举值受其资产库约束，取列表内最接近「严肃财经调查/硬朗商务」的项，首次实测后校准记录。
