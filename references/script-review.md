# 审查模块（交付前强制终审）

> 这一步把"终审"从写作里拆出来单独成篇。写完稿子会有一股"这条做完了"的完成感，最顺手的下一步就是收尾、生成封面——终审恰好卡在中间，最容易被这股惯性跳过。所以先把话说死：**终审不是收尾润色，是这条流程里最不能省的一步，它防的就是"作者自己觉得没问题"**。财经稿更没有编译器兜底，数据错一个量级就是误导真金白银，越依赖不偷懒。

## 铁规矩（三条，不可协商）

1. **必须换一双眼睛，不能作者自己再读一遍充数。** 首选起一个**独立的审核子 agent**（Claude Code 用 Task/Agent 工具，Codex 用等价能力）做对抗性终审，喂给它三样输入：① 定稿全文；② 蛋炒饭的受众画像与受众心声（见下方）；③ 阶段一抓到的当下行情与市场情绪（这只股票现在什么价、市场在吵什么）。让它按下面三层清单逐项审。环境实在起不了子 agent，就做一次硬隔离复审：彻底清空作者视角，从头逐条重核。作者对自己写的东西有盲区，这一步的全部价值就在"另一双眼睛"。
2. **只认逐条核查结果，不认一句自评断言。** 严禁用"已检查、合规、数据齐全、观点明确"这类概括声明代替终审——那是凭写作印象下的断言，还会制造"已经查过"的假象，比漏查更糟。唯一合法产出：**逐项写出结论，问题项把原句抄出来 + 指出病灶 + 给出改法**。
3. **不过就打回重写，改完重审，绝不"大差不差"放行。**

## 起子 agent 的方法（推荐做法）

用 Task/Agent 工具起一个独立审核 agent，prompt 里带上：

```
你是「蛋炒饭财经」的对抗性终审官。下面是一份财经口播稿定稿、账号受众画像、以及这只股票当下的真实行情。
请你不要复述稿子、不要夸它，只做一件事：按三层清单逐条挑毛病。
每发现一个问题，把原句抄出来 + 指出病灶 + 给出改法。没问题的项也要写一句"这项过了，因为……"。
最后给判决：PASS（三层全过）或 打回（列出所有问题）。

【定稿全文】……
【受众画像与心声】……
【当下行情与市场情绪】……
【三层清单】……（把下面三层贴进去）
```

拿到子 agent 的逐条结论后，问题项回写作环节改，改完再走一遍完整终审，直到 PASS。

## 本账号受众速览（审核时带入这个身份）

- 中国散户，主力 25-45 岁，本金几万到几十万，业余炒股、被套过、被机构收割过。
- 平时会说的话："这只股票还能拿吗""我套在 XX 了要不要割""是不是又要被主力骗了""抄底抄在半山腰"。
- 心态：又贪又怕，想抄底又怕接盘，看不懂财报但想有个明白人给句准话。

## 第一层 · 硬门禁（二值，逐条核对，任一不过即打回）

1. **零结构标注**：成稿只留能念的正文，不能有【】小标题、`0:00`/`约1:30` 时间轴、"（配 K 线图）"分镜提示、括号里的导演/朗读说明。TTS 和花生 AI 会一起念出来。
2. **零废话过场**：删掉没有信息增量的过场和自我预告（"我们先把事实讲清楚""这是最关键的一点""接下来说重点"）。判断法：删掉这句信息有没有少，没少就删。
3. **财经数据红线（本垂类最硬，逐个数字核）**：
   - 股价、涨跌幅、市值、PE、PB、PS、股息率、52 周高低，一律以 `xueqiu_quote.py` 当日返回为准，逐个和稿子里的数字比对，**量级错误（茅台标成几十块）、PE 正负写反、涨跌方向写反，任一出现即打回**。
   - 用 "股价 × 总股本 ≈ 市值""PE × 每股收益 ≈ 股价" 交叉验证关键数字量级是否合理。
   - 财报分项、行业数据核过是写稿当日最新的，不是训练记忆里的旧数据。
4. **信源主体明确**：每处引述说清主体和时间，禁止"有分析师认为""有机构预测""据报道"这类无主体信源——要么点名具体券商/机构/媒体及大致时间，要么删。
5. **事实与观点可分辨**：讲财报数字（事实）和讲该买该卖（观点）措辞上能分开，观点用"我认为""从数据看""如果是我"承接。
6. **不做保证性承诺**：全文搜一遍"必涨""稳赚""闭眼买""一定""百分百""包赚""安全边际""确定性机会"这类词，出现即打回，换成"我认为""大概率""从数据看"。爆款钩子也不能破这条。
7. **荐股红线（本垂类最容易被平台封的一条，逐句扫）**：我们没有证券投顾牌照，正文**不能给可执行的买卖操作**——结尾"不构成投资建议"兜不住，风控看正文实质。逐条扫下面五类，出现任一即打回，按 SKILL.md「荐股红线」专节改写成"看懂逻辑/该盯的信号"：
   - **具体买卖点位/操作指令**："X 块建仓""跌破 Y 止损""站上 Z 加仓""这个价位可以试探性建仓""防守位设在 X"。
   - **目标价/涨幅预测**：自己给或**转述研报给**目标价、算"还有几成空间"。
   - **分人群/分持仓操作建议**："成本 X 以下拿住""追高被套别补仓""空仓的可以进"——最典型的荐股结构。
   - **确定性/安全性话术**："安全边际""确定性机会""闭眼拿""跌不动了"（与第 6 条呼应）。
   - **诱导报仓位跟单**："你成本多少？准备加仓减仓还是不动？"——收集仓位、引导操作方向。
   - 判定口诀：帮观众看懂值不值、变量在哪 = 内容（放行）；替观众决定买不买、买在几块 = 荐股（打回）。
8. **内容合规红线（个股敏感，逐句扫，比荐股更容易踩到名誉/法律）**：聊的是具体上市公司，除了荐股，还有一类"内容本身违规"要单独逐句核——为了做钩子把没坐实的负面当事实甩出去，轻则平台限流、重则损害商誉惹官非。出现任一即打回：
   - **未坐实的负面定性当事实陈述**："财务造假""掏空上市公司""实控人跑路""业绩注水/暴雷""庄家操纵股价""马上要退市"——凡没有权威信源（监管处罚/立案、司法判决、公司正式公告、权威实名媒体报道）坐实的，一律不能写成事实，只能降级为"有投资者质疑……""这个数字市场有争议""真假待监管定论"这类留有余地的措辞，否则涉嫌诽谤、损害商业信誉。抄出原句 → 要么补权威信源坐实、要么改成质疑/待核措辞。
   - **传谣当真**：未经证实的内幕消息、小道消息、"听说要重组/被并购/有大单"、财报未正式披露的数字，不能当事实传播；只能明确标为"传闻，未经证实"或直接删。
   - **煽动与教唆**：煽动散户对立、教观众钻监管空子、暗示"跟着庄家吃肉"这类姿态，一律打回（与第三层合规立场关呼应）。
   - 判定口诀：**对公司的负面结论，问一句"这话被告上法庭我拿得出证据吗"**——拿不出就不能当事实说。
9. **正文不出现股票代码**：口播只说名字，全文不能出现 600519、300750 这类代码。
10. **前后不自相矛盾**：数字、结论、价位前后一致（如开头说看空、后文又给买入价位）。
11. **提问必须有交代（开放问题全篇最多一个）**：每个设问要么明确回答、要么留给观众互动；留给观众的最多一个（通常在结尾互动引导处）。

## 第二层 · 受众复审（变成那个散户，逐段重读）

硬门禁抓"勾选就能发现"的硬伤；这一层抓作者看不出来的"误判受众"类 AI 味。**你现在是那个被套过、又贪又怕的散户**，以他的口吻逐段吐槽，触发下面任一即标红：

- "这我早就知道了啊" → 把人尽皆知的事当猛料揭（"茅台是白马股""宁王是电池龙头""股市有风险"这类常识当独家）。
- "你这是在教我做人？当我傻？" → 居高临下、预设散户无知的措辞（"很多人可能不知道""你可能从来没想过"——开头替观众认领弱智人设）。
- "所以呢？这跟我账户里的钱有啥关系" → 抛了钩子却甩宏大叙事（从一只股票扯到宏观经济产业链），没落到"你这笔仓位该怎么办"的切身好处/威胁。
- "这开头不够让我停下来" → hook 没锚在最切身的点上（套牢、错过、该不该割）。
- "这段我划走了" → 过场、铺垫、正确的废话、连续数据轰炸的平坦段，没有信息往前推。
- "这句是把大结论当事实甩给我，凭啥？" → 强判断（"这只股票被严重高估"）后面没跟可查数据依据。
- "这例子我没听过/想半天没懂" → 举例违反"举例两关"：例子比要讲的点更陌生，或不在散户日常经验里（用一只更冷门的股票去类比、用航母/小目标当参照物）。

## 第三层 · 留存型内容的事实与立场终审

留存导向写法为抓人会主动加具体、下 judgement、抛反直觉结论——这几样最容易出事且作者自查不出。逐条硬核：

1. **真信源关（编造的具体最危险）**：把全文每一处"具体的外部事实"（财报数字、研报结论、机构名、事件、时间、排名、资金流向）拎出来逐条问：有真实信源吗？
   - ✅ 真实数据标出处 + 时间；不确定就明说"具体数字待核"。
   - ✅ 虚构的**人物细节**用"评论区有个哥们""我一个朋友"演绎框（观众默认演绎）。
   - ❌ 把编造的研报/机构评级/资金数据伪装成真实（"有券商给了 XX 目标价""北向资金大幅流入"却给不出具体出处）。**编造的具体比笼统的抽象更糟——它最像真的，最能同时骗过观众和作者，无联网时尤其高发。** 逐条标出无源的具体事实，补真信源或降级为泛化/删除。
2. **hook 时效关（重点看开头）**：hook 里凡有"现状/趋势/进展"断言（"这波要涨了""还在底部""刚反弹"），逐条核当下真实状态——尤其警惕把已兑现的行情说成将要发生。核查对象是 hook 那句话本身，不是泛泛搜选题。
3. **因果闭环关**：每个反直觉结论（"跌成这样反而是机会"）后面因果链必须补严、一步步讲清为什么。留了洞的反直觉结论就是标题党（高点击低完播、伤账号信任）。抄出结论句检查论证链有没有跳步。
4. **合规立场关（财经敏感）**：涉及监管、退市、财报造假、操纵市场等话题，姿态不能是"教你钻空子/煽动对立"。可以有态度、替散户说话，但落点收到安全区——"看懂这些不是为了追涨杀跌，是为了你下单前心里有底""不管做不做，风险自己拎得清"。全文不做保证性承诺（与硬门禁第 6 条呼应）。
5. **可执行正向收尾关**：结尾不能只留"你就等着被割吧"的消极情绪或空泛感慨。要给观众一个能带走的、可执行的东西——一个明确的观察价位、一个判断标准、一句"跌破 XX 再考虑"。从防御性焦虑转成主动掌控感，更利收藏转发。

## 终审判决（必须写出来，作为封面/存档等收尾步骤的前置凭据）

- **PASS**：三层全过。逐项写出结论（不是"都过了"三个字，是逐条给结论）。
- **打回**：把问题原句抄出来 + 病灶 + 改法，回写作环节重改，改完重走一遍完整终审。

> 阶段三生成封面、把产物写进统一文档等收尾步骤，必须在拿到终审 PASS 之后。收尾脚本会报错逼人处理，终审不会报错——正因如此更要防止"先做会报错的、把不报错的终审甩在后面"。
