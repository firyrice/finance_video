# 宇树是话题热点，为什么没接住流量？

- 日期：2026-08-13
- 分析对象：稿件《宇树上市，一签缴款七万五，打新单车变摩托》（投稿 2026-08-10 07:30）
- 对照组：京东方（8-04）、药明康德（8-01）、恒瑞（8-04）——用户反馈"播放还可以"的三支
- 触发问题（用户）：宇树上市是很大的热门，按理播放该很高，为什么这条反而不行？

## 〇、先说数据局限（重要，别把下面的结论当铁证）

- **稿件级真实数据只有五粮液一支**。宇树、京东方、药明康德、恒瑞的 `数据.md` 目前都是空模板，没有播放/完播/封面点击率。
- 所以"宇树不行、那三支还可以"这个判断，**来自用户在抖音后台的直接观察，不是 workspace 里的数字**。
- 账号级日汇总（`账号数据.md`）只能做很弱的旁证：它是每天所有在播视频的叠加值，单条新视频的流量会摊在之后好几天里，无法干净地归到某一条。
- **因此本报告是"内容机制归因"，不是"数据归因"。** 结论是"为什么这类选题结构容易吃亏"的推理，置信度已逐条标注。真正坐实，仍需把宇树那条的后台 xlsx 导进来比对完播率和封面点击率。

## 一、核心论点：宇树是"别人的事"，其余是"我的事"

这是最根上的差异，一句话概括：

> **宇树有的是"话题热度"，账号沉淀的却是"持仓焦虑流量"。这是两拨人。**

huasheng 第三节把核心受众写得很死：**被套的、观望的、纠结要不要上车的散户**，他们关心的是"我手里这只 / 我盯着这只，现在到底值不值、该不该动"。账号能稳定接住的流量，本质是**利益相关者的焦虑**。

再看这几支选题命中的是谁：

| 稿件 | 选题类型 | 观众和这只票的关系 | "我"是否被激活 |
|---|---|---|---|
| 京东方 | 套牢者代入 | 100 万存量股东，套在山顶 | ✅ 极强（我的钱正亏着） |
| 药明康德 | 催化倒计时 | 持有者赌中报，观望者纠结上车 | ✅ 强 |
| 恒瑞 | 反转答疑 | 熬了五年的创新药持有者 | ✅ 强 |
| **宇树** | **打新暴富叙事** | **还没上市、无存量套牢盘；能打新的散户极少（一签 7.5 万门槛）** | ❌ 弱（别人的暴富故事） |

宇树是**新股**。它没有存量持有者，没有"我手里正套着"的人群；一签缴款七万五的门槛，把"能参与、有切身利害"的观众筛掉了 99%。剩下的绝大多数是**围观群众**——看个热闹，看完就走，不会因为"我的钱悬着"而看完 11 分钟、更不会转发给"同样套牢的哥们"。

**热点 ≠ 与我有关。** 宇树上市是全网话题热点，但话题热度是"关注这件事"，账号要的是"关注我的仓位"。这两者在别的号（做资讯、做泛财经）可以重合，但在一个"个股深度巡礼、服务持仓决策"的号上，是错位的。

## 二、逐段拆解（进得来 / 留得住 / 传得开）

### 进得来（封面点击率 + 曝光）——中偏弱
- **标题的钩子锚在了"打新"这个绝大多数人参与不了的行为上**。"一签缴款七万五"是打新成本，"单车变摩托"是赌博暴富叙事。对照京东方"100 万人被套，可公司其实比以前更赚钱了"——后者一句话戳中"我套着"+"反直觉"，前者是"别人可能会暴富"。前者是自己的痛，后者是别人的爽。痛比爽更能驱动点击。
- **封面丢了"物证"**。按用户要求，宇树封面只放标题三行字（宇树上市 / 一签缴款七万五 / 打新单车变摩托？），主视觉是"自行车变摩托"的暴富意象。但 huasheng 第六节的封面基因要求封面是"物证"——把核心判断压成实锤（例如"219 倍 PE vs 行业 38 倍"这种反差数字）。这条封面把最有冲击力的"贵得离谱"实锤让位给了暴富叙事的意象，**对不打新的人没有代入**。京东方封面反而有明确的反转钩（暴跌 K 线 + 金色"更赚钱了"）。
- 置信度：中。封面点击率是空的，此处为机制推断。

### 留得住（5 秒完播 + 平均时长 + 完播率）——弱，且撞在枪口上
- **稿子偏长、中段是硬科技科普**。宇树稿约 3600 字 / 11 分钟，是所有稿件里偏长的。中段用了极大篇幅讲三个技术卡点（大脑没准备好 / 续航散热"两小时魔咒" / 形态方向没收敛）。这些对财经受众是"离我很远的硬科技科普"——写得很扎实，但**不是"我的钱的事"**，是"机器人行业的事"。留存单元弱，容易在这里被划走。
- **hook 缺"人"**。宇树开头是"市盈率 219 倍，一签缴款七万五。宇树科技就要上市了！"——数字冲击够，但是新闻播报式，没有具体的人、没有代入。对照京东方开头直接甩两个人（大黄蚬子精准逃顶、西红柿炒芥末山顶站岗）两种结局，"凭什么"——一秒钟把观众拽进"这可能是我"的情境。
- **撞在账号留存衰减期上**。huasheng 8.3 已记录：账号 8 月中旬进入留存力衰减期（5 秒完播从 7 月的 80-90% 滑到 65-74%，平均时长从 130-160s 降到 80-95s），当前主要矛盾就是"点进来留不住"。宇树这种"长 + 中段硬科普 + 观众非利益相关"的组合，正好是留存衰减期最扛不住的稿型。
- 置信度：中偏高。这条与账号已确认的趋势规律高度自洽。

### 传得开（点赞/收藏/评论/涨粉）——弱
- **转发动机弱**。京东方/恒瑞这类，观众会转给"同样套牢/同样在看这只的朋友"——因为对方也是利益相关者。宇树没有这个转发场景：你不会把"别人打新可能暴富"转给谁，因为你俩都参与不了。
- **收藏动机也弱**。结尾三个观察信号（中报增速/出货结构/B 端订单）确实可带走，但对"不持有、也打不了新"的人，收藏它没有决策价值。
- 置信度：中。

## 三、次要因素（别当主因，但可叠加）
- **时效窗口过了**。公告 8-06 晚，视频 8-10 发，隔了约 4 天。打新申购的最热窗口在公告后 1-2 天，等视频出来时"要不要打"的决策热度已经衰退。而京东方那种"套牢焦虑"是持续性的，没有时效衰减。
- **早 7:30 发**。五粮液数据显示早投给算法留了一天爬升、晚间自然放量——早投本身不是坏事。但这条是弱变量，样本不足，不作为主因。

## 四、结论

宇树这条不行，**不是因为它不够热，恰恰是因为它的热是"话题热"而不是"持仓热"**。账号的护城河是"服务存量散户的持仓焦虑"，而新股打新题材：
1. 没有存量套牢盘 → 激活不了核心受众的"我"；
2. 参与门槛极高（一签 7.5 万）→ 把利益相关者筛掉了 99%；
3. 稿子长 + 中段硬科技科普 → 撞在账号留存衰减期上，留不住围观流量；
4. 转发/收藏缺场景 → 传不开。

四段（进/留/传 + 选题的"我"关系）全都不占优，热点带来的那点初始曝光也就接不住、留不下。

## 五、可执行动作
1. **补数据坐实**（最高优先级）：把宇树那条的后台 xlsx 用 `python3 scripts/ingest_metrics.py --video "宇树上市，一签缴款七万五，打新单车变摩托" 导出.xlsx` 导进来，重点看**封面点击率**（验证"进得来"是否真弱）和**完播率/平均时长**（验证"留得住"是否真弱）。若封面点击率其实不低、但完播崩了 → 主因是"中段科普留不住"；若封面点击率就低 → 主因是"标题封面没勾住非利益相关者"。
2. **新股/热点题材要改造选题角度**：如果还要做类似的当红新股/纯热点票，别做"打新暴富"角度，改成能激活"我"的角度——例如"打不了新的人，怎么蹭这波"、"它上市会不会抽走你手里 XX 的血"、"同赛道已上市的 XX 会不会跟涨"，把无关观众和他的存量持仓重新挂上钩。
3. **热点票也要控长度、砍硬科普**：留存衰减期里，把中段行业科普压缩，只留和"这个价值不值、我该不该动"直接相关的部分。
4. **回写 huasheng 第八节**（本次已做，见 8.3 新增规律）。
