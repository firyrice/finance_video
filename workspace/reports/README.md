# 分析报告目录（reports/）

放置对**账号**和**稿件**的复盘分析。每一份报告都是一次"为什么"的追问——为什么这条比那条流量高、为什么吸粉差、为什么被限流——目标是把结论回写进 [huasheng.md](../huasheng.md)，驱动 skill 越做越好。

## 命名规范
`YYYY-MM-DD_<一句话主题>.md`，例如 `2026-08-13_账号流量下滑与8月4日异常复盘.md`。

## 数据来源
- 账号级：[../账号数据.md](../账号数据.md)
- 稿件级：各视频文件夹下的 `数据.md`（如 [五粮液.../数据.md](../五粮液利润翻倍，散户全在骂修改液/数据.md)）
- 原始 xlsx 在各自的 `raw/` 下，需要更细粒度时回查。

## 报告写法模板
```markdown
# <主题>
- 日期：YYYY-MM-DD
- 分析对象：账号 / 某几支稿件
- 数据区间：...

## 一、现象（先摆事实，带数字）
## 二、拆解（为什么，逐条归因，区分事实与推测）
## 三、结论
## 四、可执行的迭代动作（回写到 huasheng.md / SKILL.md 的具体项）
```

## 常见分析题目（示例）
- 某某视频为什么比某某视频流量高，但吸粉能力差？（对比播放量 vs 涨粉/完播/互动）
- 某某视频为什么会被平台限流？（看逐小时趋势是否被掐、完播与跳出是否触发风控）
- 什么类型的选题/标题/封面稳定带来高封面点击率与高完播？
